# ReadyType 1.5.1 需求说明

## 范围

1. 长语音超过 8 秒后并行启动极速和高精度识别，减少串行等待。
2. 自动识别继续遵守既有 3 秒高精度等待预算，并复用已经完成的任务，不重复发起识别。
3. 使用各引擎自身的有限质量信号，不直接比较不兼容的原始分数。
4. 向 AI 整理传递有上限的规范词表，并使用通用拼写要求替代针对单句的替换补丁。
5. 关闭 DeepSeek 思考模式、限制输出长度，并分别展示识别耗时与整理和输入耗时。
6. 不开放尚未完成的 1.6.0 选中文字语音操作。

## 验收标准

- 全量自动化测试、正式构建、签名检查、打包、UI 门禁和敏感信息扫描通过。
- 发布工作流生成版本匹配的 ZIP、DMG 和 SHA-256 校验文件。
- 公开版本与构建号为 `1.5.1 (96)`。
