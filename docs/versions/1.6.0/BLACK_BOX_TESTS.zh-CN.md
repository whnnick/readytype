## 必测失败路径

- 处理中切换 App。
- 处理中改变或取消选区。
- 当前 App 不支持读取或替换选区。
- DeepSeek 密钥缺失、无额度、限流、网络中断和服务错误。
- 选中文字超过 8,000 字符。
- 录音中按 `Esc` 或点击关闭。
