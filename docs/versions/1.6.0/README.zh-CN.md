# ReadyType 1.6.0

ReadyType 1.6.0 的主题是“更懂你正在写什么”。本版本在不增加常驻操作负担的前提下，统一当前 App、窗口、选中文字、用户口述和手动设置，让 ReadyType 自动选择适合的输出方式与语气。

## 核心范围

- 选中文字后，可直接说“改短一点”“更自然”“翻译成英文”“帮我回复”等指令。
- 统一 `Context Engine`，按明确优先级判断输入意图、App 类型、语气和输出语言。
- 微信、QQ 等个人聊天保持简短自然；飞书、Slack、Teams 保持清楚直接；邮件、笔记、文档和 AI 工具使用各自适合的结构。
- 替换选中文字前重新验证目标与选区；目标变化时保留原文并复制结果，禁止写入错误窗口。
- 统计只记录匿名动作类型、场景分类、结果和耗时，不记录选中文字、口述内容、窗口标题或 App 名称。

## 不在本版本

- 监听用户后续修改并自动学习。
- 静默加入常用词或保存完整输入历史。
- 实时双引擎流式替换、方言扩展、跨平台版本或更多大模型供应商。

确认式纠正学习作为 1.7.0 候选，必须建立在 1.6.0 的上下文与安全选区基础上。
